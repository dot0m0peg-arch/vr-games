# Miner (browser build)

The owner's Miner game: a single-file Three.js build (`index.html` + `three.min.js`) with its Fredoka variable font, icons, web app manifest and a service worker for offline play. It is copied from the owner's Miner project; update it by copying the new build over this folder. Make code fixes in the source project first, or the next copy undoes them.

Public entry: https://dot0m0peg-arch.github.io/vr-games/games/miner/

Plays in any browser. VR mode is not yet verified on a headset. Follow [the game integration guide](../../docs/ADDING-GAMES.md) and update the root collection status only to what was tested.
