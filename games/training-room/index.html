Controls

VR (Quest)

  • A or X held: talk
  • Y: mic off / on
  • B: menu
  • Left stick: move (click to sprint)
  • Right stick: snap turn, push forward to teleport
  • Squeeze: grab and hold, release to drop or throw
  • Trigger: point and click the menu
  • Marker in hand: trigger draws, then say “AI, make it real”

Desktop

  • Click the field to look (Esc frees the mouse)
  • WASD or arrows: move, Shift: sprint
  • Hold V: talk, M: mic off / on
  • Enter: type a command
  • E: grab / drop, left click: swing
  • F: magic marker, drag to draw
  • Z: undo

Phone companion

  • Big button: hold to talk
  • Mic switch: hard mute
  • Command box and part chips
  • Drag the view to look, joystick to walk
  • Follow the headset player’s view
  • Share your camera onto a screen
  • Draw: sketch something and make it real
Connect your laptop and phone
  1. On the laptop, run node games/training-room/bridge/server.mjs from the repository folder (Windows: double-click bridge/start-bridge.cmd). It prints an address, a room key and a QR code.
  2. Windows asks whether Node.js may use the network: allow Private networks, and set the laptop’s Wi-Fi network profile to Private, or the headset and phone cannot connect.
  3. On the headset, open the printed https://<laptop-ip>:8787/?k=KEY. Accept the self-signed certificate warning; it can come back after the laptop moves to another network.
  4. On the phone, scan the QR code in the bridge window and accept the warning too. On the laptop, open http://localhost:8788/?k=KEY; Menu → People shows the QR code again.
  5. Optional local AI: install Ollama with a coding model for commands, and run a whisper.cpp server for voice. Without them the built-in parser still works.
